How these are worked out

  • Claude Code clones the GitHub repo when someone adds the Viaduct marketplace. GitHub reports unique cloners per day but keeps only 14 days, so a daily job saves each day.
  • Clones from Viaduct's own CI runs are removed. A floor of 4 unique clones a day is assumed to be bots, archivers and mirrors.
  • The same person can clone again on a later day (updates, a second computer), so 60% of what's left is counted as new people (range 40–90%).
  • The directory edition downloads its engine from the release page on first use, so those counts are exact (minus test downloads).
  • Stars, forks and release downloads are fetched live from GitHub; the rest updates daily.
